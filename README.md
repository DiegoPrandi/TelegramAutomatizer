# Telegram Automatizer

Projeto desenvolvido com foco em automação e gerenciamento de mensagens no Telegram.

A ideia principal do sistema é permitir um controle mais organizado sobre mensagens agendadas, mídias, templates e múltiplas contas do Telegram, criando uma plataforma mais prática e eficiente para automação de envios.

## 📌 Objetivo do Projeto

Atualmente o Telegram já possui um sistema de mensagens agendadas, porém de forma limitada para gerenciamento em maior escala.

O objetivo deste projeto é criar uma plataforma própria para:

* Agendar mensagens
* Organizar mídias
* Criar templates reutilizáveis
* Gerenciar múltiplas contas
* Automatizar envios
* Centralizar tudo em uma interface própria

ao decorrer do desenvolvimento, pretendo adicionar novas funcionalidades. Porem inicialmente o foco sera somente nas principais listadas acima
